도움이 필요하신가요?

jack2718@naver.com으로 사용 중인 iPhone 모델, iOS 버전, 문제가 발생한 순서를 보내주세요. 얼굴이 나온 원본 사진은 문의에 꼭 필요한 경우에만 자발적으로 첨부해 주세요.

사진 보정 흐름

  1. 사진 고르기에서 편집할 사진을 선택합니다.
  2. 색감과 얼굴 형태를 먼저 조정합니다.
  3. 잡티 도구는 깨끗한 피부를 샘플로 고른 뒤 보정할 곳을 누릅니다. 변형 도구는 필요한 부분을 살짝 드래그합니다.
  4. 저장 메뉴에서 사진 앱에 보정본을 추가합니다. 원본은 변경하지 않습니다.

저장이 안 될 때

iPhone 설정에서 Mellow Photo의 사진 추가 권한과 기기 저장 공간을 확인해 주세요. 고해상도 사진에서 문제가 생기면 원본 해상도 옵션을 끄고 저장하세요.

지원 범위

iOS 17 이상 iPhone을 대상으로 개발 중입니다. 자동 AI 잡티 제거, HDR·Live Photo 영상·ProRAW 보존은 지원하지 않습니다. 기본 출력은 긴 변 최대 4096픽셀의 SDR JPEG입니다.

작업 삭제

편집에서 사진 빼기를 선택하면 앱 내부 작업 사본과 보정 기록을 제거합니다. 사진 앱에 있는 원본과 이미 저장한 보정본은 그대로 남습니다. 앱을 삭제하면 앱 내부 작업 기록이 사라집니다.
