개인정보 안내

적용 대상: Mellow Photo iPhone 앱
시행일: 2026년 10월 13일

기기에서 처리하는 사진

사용자가 Apple 사진 선택기에서 직접 고른 사진의 사본을 앱 내부에 저장하여 편집합니다. 사진 보관함 전체를 읽는 권한은 요청하지 않습니다. 보정본을 사진 앱에 저장할 때 사진 추가 권한을 요청합니다.

얼굴 분석

피부 정돈과 얼굴 미세 조정을 위해 Apple Vision으로 얼굴 위치와 눈·입 등 특징점을 기기에서 계산합니다. 얼굴의 신원을 식별하거나 인증하지 않습니다. 얼굴 특징점과 사진은 개발자 서버나 제3자 보정 서버로 전송하지 않습니다. 특징점은 처리 중 메모리에서 사용하고 별도의 얼굴 데이터 파일로 보관하지 않습니다.

작업 기록 보관과 삭제

선택한 사진의 작업 사본, 보정 설정, 실행 취소·복귀 기록, 사용자 프리셋을 앱 내부에 보관합니다. 작업 폴더는 기기 백업 대상에서 제외합니다. 편집에서 사진을 빼면 해당 사본과 작업 기록을 삭제합니다. 앱 삭제 시 앱 내부 기록이 제거됩니다. 사진 앱에 내보낸 결과는 사용자가 사진 앱에서 관리합니다.

서버 수집과 외부 서비스

앱에는 회원가입, 광고, 사용자 추적, 별도 분석 SDK가 없습니다. 개발자가 운영하는 서버로 사진·얼굴 정보·편집 기록을 수집하지 않습니다. iCloud 사진 다운로드, Apple 사진 앱의 동기화, App Store 및 운영체제 진단 기능에는 사용자의 Apple 설정과 Apple 개인정보 처리방침이 적용됩니다.

지원 문의

사용자가 이메일로 문의하면 답변을 위해 발신 이메일 주소와 문의 내용을 이용합니다. 지원 주소는 jack2718@naver.com입니다. 문의에 사진을 첨부하는 것은 선택이며 민감한 사진은 보내지 않아도 됩니다. 문의 정보 삭제 요청은 같은 주소로 보내주세요. 메일 서비스의 보관·처리에는 해당 서비스의 정책도 적용됩니다.

이 안내 페이지

지원 페이지는 GitHub Pages로 제공됩니다. 페이지에는 별도 분석 코드나 추적 쿠키를 넣지 않았습니다. 호스팅 서비스가 보안·운영 목적으로 처리하는 접속 정보에는 GitHub 개인정보 처리방침이 적용됩니다.

변경 안내

앱의 데이터 처리 방식이 바뀌면 이 페이지와 앱 안내를 갱신합니다.
