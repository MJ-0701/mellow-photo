# 체형 생성 사진 세트(가상 인물)

모든 인물은 가상이며 실존 인물과 무관하다.

## 생성

- 도구: codex-cli 0.163.0(`codex exec`), OpenAI 이미지 생성 도구(codex 내장 `image_gen`).
- 날짜: 2026-10-21.
- 원본: 1024×1024 PNG. 저장소에는 `sips -Z 1024 -s format jpeg -s formatOptions 90`으로 바꾼 JPEG만 둔다.
- 모든 프롬프트에 "fictional people who do not resemble any real person or celebrity, no text, no watermark, no logos"를 넣었다.
- 생성 호출은 모두 여덟 번이었다(첫 세트 다섯 번, `torso-01` 재생성 한 번, `couple-body-01` 재생성 두 번). `couple-body-01`은 모두 세 번 만들었고 생성 예산을 다 썼다.
- `torso-01`의 첫 프롬프트("fitted sleeveless black top … arms held slightly away from the torso")는 이미지 도구의 안전 필터가 거절해 사진이 나오지 않았다. 옷차림과 팔 자세를 풀어 쓴 두 번째 프롬프트로 만들었다.

### 다시 만든 사진(2026-10-21)

- `torso-01`: 첫 사진은 팔을 내린 자세라 부유방 높이(어깨~엉덩이 27%)에서 위팔이 옆가슴에 붙어 부유방 효과를 잴 수 없었다. 두 손을 허리에 짚고 팔꿈치를 벌려 위팔과 옆가슴 사이로 배경이 보이게 다시 만들었다. 화면 오른쪽은 겨드랑이 가까이에서 틈이 좁다.
- `couple-body-01`: 첫 사진은 엉덩이에서 잘려 Vision 엉덩이 관절 신뢰도가 0.3 아래(0.277·0.290)였다. 머리부터 정강이까지 보이게, 두 사람이 가깝되 닿지 않게 다시 만들었다.
- `couple-body-01` 두 번째 사진은 얼굴이 작아(폭 약 10%) Vision이 남자 얼굴을 찾지 못했고 팔을 내린 자세라 부유방 높이에서 팔이 몸통에 붙었다. 머리부터 허벅지까지, 얼굴 폭 약 12%, 두 사람 모두 손을 허리에 짚고 팔꿈치가 서로 닿게 다시 만들었다(마지막). 위팔이 겨드랑이 아래 몸통에 붙어 부유방 옆선은 없다. 이 사진은 남녀·이웃 규칙만 확인하고 부유방 이동은 `torso-01`에서 확인한다(컨트롤러 판정).
- 두 장 모두 codex 샌드박스가 작업 폴더 저장을 막아 `~/.codex/generated_images`의 생성 파일을 복사했다(원본 1254×1254, 1024 JPEG로 변환).

## 용도

- 저장소 안 자동 수용 테스트(`apple/Tests/MellowRenderingTests/Fixtures/body/`에 사본).
  - `chin-01`: 이중턱 워프와 턱밑 그늘.
  - `torso-01`: 부유방·가슴 옆선, 허리·팔 보호와 실루엣 이동, 격자 합성 직선.
  - `couple-body-01`: 얼굴과 몸의 짝, 사람별·성별 체형 값(남녀 규칙), 옆 사람 보호. 부유방 이동은 재지 않는다(옆선 없음).
  - `lines-01`: 실루엣 근처를 뺀 배경 직선 보존.
- 수동 확인.

Vision이 생성 사진에서 실사진과 다르게 동작할 수 있다.

## 사용 조건

생성물의 권리와 사용 조건은 OpenAI 이용 약관을 따른다.
저장소 밖 배포·마케팅에 쓰지 않는다.
최종 확인은 사용자 조치다.

## 라벨 형식(`labels.json`)

- `version`: 형식 버전(현재 1).
- `photos[].file`: 이 폴더의 파일 이름.
- `photos[].notes`: 생성 조건을 눈으로 확인한 결과다.
- `photos[].people`: 사진 속 사람을 왼쪽부터 나열한다. 눈으로 확인한 값이다.
  - `gender`: `male`·`female`.
  - `ageBand`: `child`·`young`·`adult`·`senior`.
  - `glasses`: 안경 착용 여부.
  - `pose`: `frontal`·`turned`·`profile`.
  - `occlusion`: `none`·`partial`(손·다른 사람 등으로 몸이나 얼굴 일부 가림).
  - `ambiguous`: 눈으로 봐도 성별이 모호하면 `true`.
