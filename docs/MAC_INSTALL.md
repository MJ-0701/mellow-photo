# Mellow Photo — Mac 설치와 첫 보정

macOS 14 이상이 필요합니다. 전달용 앱에는 Apple Silicon(M1 이상)과 Intel 실행 파일이 함께 들어 있습니다. 실제 실행 검증은 Apple Silicon Mac에서 진행하며 Intel 실기기는 아직 검증하지 않았습니다. Xcode나 개발자 계정은 사용자의 Mac에 필요하지 않습니다.

## 사람이 확인할 것

사진을 가져온 뒤 **빠른 보정**에서 목적별 버튼을 고르면 됩니다. **사진에 맞게 자동**은 밝기·색감·선명도 등 기존 값을 교체하고 얼굴이 있으면 인물 원터치를 적용합니다. **인물 원터치**의 기본 적용은 이 사진의 모든 얼굴에 피부·눈·입·메이크업과 몸 피부 밝기를 묶어 적용하며 기존 개인 조정을 유지합니다. 전체·그룹 원터치에서 기존 개인 조정이 있으면 주 버튼을 누른 자리에서 적용 방법을 선택합니다. **기존 조정 유지**는 기본 적용을, **개인 조정도 이 강도로 적용**은 해당 인물의 준비된 원터치 항목 교체를 수행합니다. 개인 교체는 사진 전체의 색감·몸 피부 밝기·배경을 바꾸지 않습니다. 선택하기 전이나 취소했을 때는 사진을 바꾸지 않으며, 두 적용 방식 모두 얼굴형·체형·자르기·수동 브러시는 유지합니다.

**배경 흐림**은 강도 35%, **밤 색감**은 밤 필터와 강도 60%로 현재 값을 교체하므로 연타해도 누적되지 않습니다. 밤 색감은 조명이나 장면을 새로 만드는 기능이 아닙니다. **어두운 사진 밝히기**는 노출만 올리고 이미 더 밝은 조정은 유지합니다. 사용할 수 없는 기능은 이유를 표시합니다.

여러 장은 **사진마다 자동 보정**으로 각각 분석하세요. **이 설정 복사**는 선택한 사진의 값을 그대로 복사합니다. 처리 중 **나머지 취소**는 이미 완료한 사진을 유지하고 미처리 사진은 바꾸지 않습니다. 일부 실패·미처리 건수도 안내합니다. 각 사진의 실행 취소·다시 실행과 원본 비교를 사용할 수 있습니다.

## 에이전트 참조

### 개인 맥북에서 GitHub 소스로 실행하기

이미 GitHub 소스 접근 권한이 있는 개인 맥북에서는 정식 배포나 Apple Developer 활성화 없이 로컬로 빌드할 수 있습니다. 빌드에는 Xcode 전체 버전이 필요합니다(Command Line Tools만으로는 빌드할 수 없습니다). 아래 명령은 GitHub CLI로 로그인된 환경을 기준으로 합니다.

```sh
gh repo clone MJ-0701/mellow-photo
cd mellow-photo
./scripts/package-mac.sh
open "apple/build/Build/Products/Release/Mellow Photo.app"
```

`scripts/package-mac.sh`는 Apple Silicon·Intel 통합 Release 앱을 빌드해 임시 서명하고, 이 안내를 포함한 전달용 `dist/Mellow-Photo-Mac.zip`과 SHA-256 파일도 만듭니다. 최신 소스를 받으려면 해당 폴더에서 `git pull --ff-only` 후 다시 실행합니다. GitHub 비공개 저장소이므로 접근 권한이 있는 계정으로 받아야 합니다. 빌드 후에는 앱을 응용 프로그램 폴더에 복사해 더블클릭으로 실행할 수 있습니다. 아래 압축 파일 전달 방식은 선택 사항입니다.

## 빌드된 앱을 복사해서 설치하기

1. 전달받은 Mellow-Photo-Mac.zip을 더블클릭해 압축을 풉니다.
2. Mellow Photo.app을 응용 프로그램 폴더로 옮깁니다.
3. 앱을 더블클릭합니다.

현재 전달본은 개발 중인 앱이며 Apple 공증을 받지 않았습니다. macOS가 개발자를 확인할 수 없다는 이유로 실행을 차단할 수 있습니다. 본인이 전달받은 앱인지 확인한 경우에만 시스템 설정 → 개인정보 보호 및 보안에서 이 앱에 대한 ‘확인 없이 열기’를 직접 선택할 수 있습니다. 보안 기능 전체를 끌 필요는 없습니다. 악성 소프트웨어 또는 파일 손상 경고라면 실행하지 말고 새 전달본을 요청하세요.

Apple의 공식 안내: https://support.apple.com/ko-kr/102445

## 아이폰 사진을 보정하기

1. 아이폰에서 사진을 AirDrop으로 Mac에 보내거나, iCloud 사진으로 Mac 사진 앱에 동기화합니다.
2. Mellow Photo에서 ‘사진 가져오기’를 누르고 ‘사진 앱에서 고르기’ 또는 ‘파일에서 고르기’로 HEIC·JPEG·PNG를 선택합니다. 파일을 편집 화면으로 끌어다 놓아도 됩니다. 한 번에 편집할 수 있는 사진 수는 Mac 메모리에 따라 12·24·40장입니다.
3. 먼저 **빠른 보정**에서 목적을 고릅니다. 각 카드의 **강도 조절**을 누르면 상세 도구로 이동합니다. 원본 비교와 한 단계 되돌리기로 결과를 확인합니다.
4. 잡티 보정은 깨끗한 피부를 클릭해 샘플을 정한 다음 잡티를 클릭합니다. 샘플 위치는 Option+클릭으로 바꿉니다. 부분 변형은 조금씩 드래그합니다.
5. 원본과 비교한 뒤 ‘저장’ 메뉴에서 형식을 고르고 저장할 폴더를 선택합니다. 파일은 `<이름>_mellow.jpg`처럼 새 이름으로 저장되며 기존 파일을 덮어쓰지 않습니다. 저장한 사진을 AirDrop으로 아이폰에 보내면 됩니다.

⌘O 가져오기, ⌘Z 실행 취소, ⇧⌘Z 다시 실행, ⇧⌘S 현재 사진 저장입니다.

사진 원본은 수정하지 않습니다. 로그인·초대코드·구독 없이 사용할 수 있으며 사진 보정은 Mac 내부에서 처리됩니다.

Mac 버전도 편집 기록을 복원합니다. 가져온 사진은 앱 안의 작업 사본으로 보관하므로, 앱을 다시 열면 사진 목록·보정값·실행 취소 기록·프리셋이 그대로 남아 있습니다. iPhone 앱과 편집 기록을 동기화하지는 않습니다. ‘편집에서 사진 빼기’는 작업 사본만 지우며 원래 파일은 그대로입니다.

앱은 macOS App Sandbox 안에서 실행되며 사용자가 고른 파일과 폴더만 읽고 씁니다. 작업 사본과 기록은 `~/Library/Containers/com.mj.mellowphoto/Data/Library/Application Support/MellowPhoto`에 있습니다. 이전 버전의 Mac 앱을 쓰던 경우, 새 버전을 처음 실행할 때 macOS가 예전 `~/Library/Application Support/MellowPhoto` 폴더를 이 위치로 옮기고, 앱이 그 안의 저장 프리셋(`presets.json`)을 가져온 뒤 `presets.json.imported`로 이름을 바꿉니다.

출력은 8bit sRGB SDR이며 기본은 긴 변 최대 4096픽셀입니다. ‘원본 해상도’를 켜면 크기 제한 없이 저장합니다. HDR·Live Photo 영상·RAW/ProRAW 편집과 원본 GPS/카메라 정보 보존은 지원하지 않습니다. 피부 정돈·자동 잡티·인물 원터치는 기존 사진의 피부를 다듬는 보정입니다. 모든 잡티를 지우거나 새로운 피부를 생성하는 기능은 아닙니다.
