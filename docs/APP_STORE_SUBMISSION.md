## 기능과 설명의 근거

소개 문구는 현재 iPhone 화면과 보정 엔진에 있는 기능만 포함합니다: 색감 슬라이더, 프리셋, 얼굴 감지 기반 피부 정돈·미세 조정, 수동 복제 브러시, 부분 변형, 최대 12장, 설정 전체 적용, 실행 취소·복귀, 작업 기록 저장, JPEG 출력. AI 자동 잡티 제거, 생성형 보정, Evoto와 동일한 성능, HDR 보존, 무제한 고해상도 성능은 약속하지 않습니다. 실제 빌드의 기능이 바뀌면 문구도 함께 수정하세요.

### 저장소 재구성(2026-10-14) 이후 다음 제출 전에 확인할 점

- 앱 소스는 `apple/`로 옮겼습니다. Xcode 프로젝트는 `apple/MellowPhoto.xcodeproj`(스킴 `MellowPhoto`, 정의는 `apple/project.yml`), 버전은 `apple/Config/Version.xcconfig`, 배포 태그는 `apple-vX.Y.Z`입니다. 안내는 [APPLE.md](APPLE.md)와 [IOS_RELEASE.md](IOS_RELEASE.md)에 있습니다.
- 같은 앱이 iPad도 지원합니다(`TARGETED_DEVICE_FAMILY = 1,2`). App Store Connect가 요구하는 iPad 스크린샷을 실제 iPad 화면으로 준비해야 합니다.
- 한 번에 편집할 수 있는 사진 수가 기기 메모리에 따라 12·24·40장으로 바뀌었습니다. `fastlane/metadata/ko/description.txt`, `fastlane/metadata/ko/release_notes.txt`, `fastlane/metadata/review_information/notes.txt`의 "최대 12장"/"Up to 12" 문구는 아직 출시본 기준이므로 다음 제출 전에 실제 동작에 맞게 고칩니다.
- 사진 앱 선택 외에 파일 선택으로도 가져올 수 있고, PNG 저장을 고를 수 있습니다. 소개 문구를 바꿀 때 반영할 수 있습니다.
- Mac App Store 사용 가능 여부는 계속 끈 상태로 둡니다. Mac 앱은 임시 서명 zip으로만 전달합니다.

앱 이름 사용 가능 여부와 권리 확인은 App Store Connect에서 진행합니다. 첫 버전은 release notes가 표시되지 않거나 불필요할 수 있습니다. 저작권 표기에는 계정 소유자가 사용할 실제 권리자 이름을 입력해야 하므로 저장소에서 이름을 추측하지 않습니다.

## 초대코드 입력 화면을 넣지 않은 이유

현재 앱은 회원가입·초대코드 없이 바로 사진을 고를 수 있습니다. 사용자는 “심사 문제가 없을 때만 초대코드”를 원했으므로, 이번 첫 공개 버전에는 보정 도구 전체를 막는 초대코드 관문을 추가하지 않았습니다.

초대형 앱이 일괄 금지된다는 의미는 아닙니다. Apple은 심사자가 전체 기능에 접근할 수 있고, 기능과 접근 조건이 메타데이터에 정확히 설명되기를 요구합니다. 초대코드가 필요한 설계라면 실제 목적, 사용자 접근 경로, 유효한 심사용 접근 수단을 명확히 제공해야 합니다. 단순히 특정 사람만 쓰게 하려고 일반 사진 편집 기능을 잠그면 심사 설명과 검증 부담이 늘어날 수 있다는 판단입니다. 승인 여부를 미리 보장할 수 없어 이번 범위에서 제외했습니다. 숨은 코드, 심사 이후 활성화할 잠금, 심사자만 다른 기능을 보여주는 분기도 없습니다.

특히 디지털 편집 기능 전체를 자체 코드로 해제하는 설계는 3.1.1의 자체 기능 잠금 해제 제한과 충돌할 소지가 있습니다. 유료 기능 잠금 해제와 무료 초대 서비스의 맥락은 구분해야 하며, 모든 초대형 앱이 금지된다는 뜻은 아닙니다.

근거: [Apple App Review Guidelines의 Before You Submit·2.1·2.3.1·3.1.1](https://developer.apple.com/app-store/review/guidelines/). 이 문단은 해당 요구사항을 현재 앱에 적용한 판단이며 Apple의 개별 심사 결과를 대신하지 않습니다.

## 심사자 안내 요약

로그인이나 데모 계정이 필요하지 않습니다. 시스템 사진 선택기에서 정면 인물 사진을 가져온 뒤 색감 → 인물 → 잡티·변형 순서로 확인합니다. 얼굴이 감지되지 않으면 인물 슬라이더 대신 다른 사진 또는 수동 도구를 사용합니다. 수동 보정 이후 얼굴 형태 슬라이더 잠금은 보정 좌표를 지키기 위한 의도된 동작입니다.

저장은 현재 사진 또는 전체 사진을 새 JPEG로 추가하는 방식입니다. 최초 저장에서만 사진 추가 권한을 요청합니다. 권한을 거절해도 편집은 가능하고 저장 시 안내합니다. iCloud 원본 다운로드를 제외한 보정은 기기 내부에서 실행하며, 지원 링크·이메일을 열 때만 외부 앱/페이지로 이동합니다. 계정·광고·결제 기능이 없습니다.

심사 연락처의 이름·전화번호·이메일은 App Store Connect에서 실제 연락 가능한 정보로 완성해야 합니다. 이메일 후보는 사용자가 제공한 `jack2718@naver.com`이며 이름과 전화번호는 임의 작성하지 않습니다. 공개 지원 URL과 개인정보 URL의 접근 여부를 제출 직전에 다시 확인하세요.

## 스크린샷 계획

앱을 실제 실행한 iPhone 화면으로 다음 장면을 촬영합니다. 설명용 합성 화면을 실제 앱 화면처럼 제출하지 않습니다.

1. 인물 사진을 연 색감 화면: “내 취향에 맞게 색감을 조절해요.”
2. 인물 화면: “피부와 얼굴을 조금씩 다듬어요.”
3. 잡티 도구 화면: “깨끗한 부분을 골라 직접 보정해요.”
4. 여러 사진과 저장 메뉴: “마음에 드는 설정을 여러 사진에.”

사진은 사용·공개 권한을 확보한 인물 사진을 사용합니다. 실사용자의 사진이나 개인정보를 동의 없이 스토어 자료에 쓰지 않습니다. 필요한 기기 크기와 개수는 현재 App Store Connect가 표시하는 요구사항을 따릅니다. 스크린샷과 실기기 검증은 정적 빌드 테스트로 대체하지 않습니다.
