# Mellow Photo

아이폰 인물·셀카를 맥에서 편집하는 작은 로컬 사진 보정 앱입니다. 사진이나 얼굴 데이터를 서버로 업로드하지 않으며, 가입과 API 키가 필요 없습니다.

## 실행

macOS 14 이상, Apple Silicon 맥에서 개발·검증했습니다. 개발에는 Swift 5.9 이상과 Apple Command Line Tools 또는 Xcode가 필요합니다. 외부 패키지 의존성은 없습니다.

```sh
./scripts/build-app.sh
open "dist/Mellow Photo.app"
```

빌드된 앱을 응용 프로그램 폴더에 복사하면 이후에는 더블클릭으로 실행할 수 있습니다. 현재 버전은 로컬 실행용 임시 서명만 사용하며 배포·공증하지 않았습니다.

## 첫 보정

1. **사진 가져오기** 또는 드래그로 HEIC·JPEG·PNG를 추가합니다. 한 번에 최대 40장을 편집합니다.
2. **색감**에서 노출·대비·채도·따뜻함 또는 내추럴·포근한·클린 프리셋을 선택합니다.
3. **인물**에서 감지된 얼굴을 선택하고 피부 정돈·얼굴 미세 조정을 사용합니다. 얼굴 번호는 화면 왼쪽부터입니다.
4. **도구 → 잡티 보정**에서 깨끗한 피부를 한 번 클릭하고, 잡티를 클릭합니다. 샘플 위치는 Option+클릭으로 바꿉니다.
5. **부분 변형**에서 얼굴·체형의 일부를 조금 드래그해 조정합니다. 배경도 움직일 수 있으므로 원본과 비교하며 사용합니다.
6. **내보내기**에서 JPEG/PNG 형식과 현재 사진/전체 사진을 선택하고 폴더를 지정합니다.

수동 잡티 보정·부분 변형을 시작하면 얼굴 미세 조정과 얼굴 선택은 잠깁니다. 위치가 어긋나지 않도록 얼굴 형태부터 조정하세요. 실행 취소로 수동 작업을 모두 되돌리거나 초기화하면 다시 조정할 수 있습니다. 프리셋·전체 적용도 수동 작업이 있는 사진의 얼굴 형태는 유지합니다.

⌘O는 가져오기, ⌘Z는 실행 취소, ⇧⌘Z는 다시 실행, ⇧⌘S는 현재 사진 내보내기입니다. 앱 종료 시 현재 편집 기록은 사라집니다. 사진을 먼저 내보내고, 반복 사용할 슬라이더 값은 프리셋으로 저장하세요.

## 구현된 범위

- ImageIO 기반 EXIF 방향 보정과 HEIC/JPEG/PNG 읽기
- Vision 얼굴 특징점과 눈·입 보호 영역을 이용한 얼굴 피부 필터
- 얼굴 양옆의 약한 국소 변형, 수동 드래그 변형
- 샘플 영역을 부드럽게 합성하는 수동 복제 브러시
- 색감 조정, 사용자 프리셋 저장, 전후 비교, 사진별 실행 취소
- 사진마다 인식한 얼굴 위치를 사용한 슬라이더 설정 일괄 적용
- 축소 미리보기와 원본 해상도 저장, 기존 파일을 덮어쓰지 않는 저장

## 첫 버전의 한계

피부 정돈은 마스크 기반 필터입니다. 학습 모델 기반 자동 잡티 탐지, Evoto와 동일한 보정 품질, 자동 전신 체형 인식은 구현하지 않았습니다. 얼굴을 찾지 못하면 얼굴 슬라이더를 제공하지 않으며 수동 도구는 사용할 수 있습니다. 미리보기는 긴 변 최대 1600픽셀이라 원본 해상도 저장 결과의 세부 질감은 다를 수 있습니다.

출력은 호환성을 위한 **8bit sRGB SDR JPEG/PNG**입니다. HDR/gain map, Live Photo 영상, RAW/ProRAW 편집, 원본 색공간 그대로의 재출력은 지원하지 않습니다. 출력에 원본의 GPS·카메라 EXIF는 복사하지 않습니다. 원본 파일은 변경하지 않습니다. 각 사진의 잡티 위치와 수동 변형은 다른 사진으로 복사하지 않습니다.

프리셋만 `~/Library/Application Support/MellowPhoto/presets.json`에 보관합니다. 사진·보정 기록은 메모리에만 유지합니다. Evoto 코드·모델·프리셋·그래픽 자산은 이 저장소에 포함하지 않았으며 독립 구현입니다.

## 검증

```sh
./scripts/test.sh
```

XCTest가 없는 Command Line Tools 환경에서도 독립 실행하는 실제 렌더링 테스트입니다. 이미지 방향, no-op, 색감과 따뜻함 방향, 국소 변형·복제, 원본 해상도 저장 및 이름 충돌을 검사합니다. macOS 그래픽 서비스가 차단된 CI/샌드박스에서는 Core Image GPU 테스트에 접근 가능한 실행 환경이 필요합니다.

코어: `Sources/MellowCore` · UI: `Sources/MellowApp`. `CIWarpKernel(source:)`는 기존 Core Image API라 현재 SDK에서 deprecation 경고가 발생합니다. 지원이 제거되는 OS에 대응할 때 Metal 커널로 교체해야 합니다.
